# ESP Virtual Keyboard · 固件升级工具

本工具用于给 ESP32-C3 BLE 虚拟键盘烧录预编译固件，并在网页上完成 WiFi 配网，全程无需安装 Arduino IDE。

- 网页版（推荐）：浏览器 + Web Serial 烧录与配网（仅 Chrome / Edge 89+）
- 命令行兜底：`flash_cli.bat`（仅烧录，不含配网）

---

## 一、快速升级（网页 GUI）

1. **准备**：USB 数据线（Type-C，必须是数据线）连接键盘设备与电脑；Chrome 或 Edge 浏览器。
2. 双击 `一键升级.bat`，浏览器自动打开 `http://127.0.0.1:8123/`。
3. 勾选或取消「擦除全部数据」：
   - **勾选（默认）**：清空全部 Flash（含已保存的槽位/序列/BLE 名/已配 WiFi），升级后由工具自动配网。
   - **取消勾选**：保留已保存配置（仅覆盖固件）。
4. 填写 WiFi 信息（**可选**）：
   - SSID / 密码：烧录完成后自动经串口写入设备 NVS；
   - 「覆盖固件内置的 WiFi 凭据」：默认不勾选；勾选后本次配网**持久压过**固件内置凭据。
5. 点击「连接设备」，在弹窗中选择设备串口。
6. 点击「开始升级」，等待进度条走完；若填写了 WiFi，会自动配网并弹「✅ 固件已写入并配网成功（IP …）」。
7. 关闭「一键升级」窗口即退出工具。

> 升级中**请勿断电、请勿拔线**。升级失败或变砖：重新运行本工具重刷，或用 `flash_cli.bat` 恢复；保留旧版升级包即可回退旧固件。

## 二、配网

| 入口 | 作用 |
|---|---|
| 随升级自动配网 | 烧录完成后自动下发 WiFi 并等待连接成功 |
| **仅配网** | 不刷固件，只修改/写入 WiFi 凭据（NVS 持久） |
| **清除配网信息** | 清除 NVS 凭据与覆盖标志，回落到固件内置凭据 |

- **覆盖开关语义**：
  - 对**空凭据固件**（本工具分发包）：不勾选覆盖也已持久（NVS），重启后自动连接；
  - 对**含内置凭据固件**（自己用 IDE 编译且 `config.h` 填了凭据）：不勾选覆盖时本次配网**仅临时生效**，重启回内置；要持久覆盖请勾选。
- 配网成功后设备会自动重连（断电重启后仍生效，NVS 持久）。

## 三、命令行兜底（`flash_cli.bat`）

```
flash_cli.bat            # 默认全擦除后烧录
flash_cli.bat --no-erase # 保留配置烧录
```

- 自动探测 C3 串口并烧录（dio / 80m / 4MB，偏移 0x0 / 0x8000 / 0xE000 / 0x10000）。
- 命令行**不含配网**；需要配网请用网页工具「仅配网」。

## 四、维护者：构建固件包

1. 修改工程 `config.h`：
   - `FW_VERSION`（当前 `"20260916"`，建议按日期递增）；
   - `WIFI_SSID` / `WIFI_PASSWORD` **可保留你的真实凭据**——构建脚本会在**副本**中强制置空并断言，分发包不含任何凭据。
2. 双击 `build_package.cmd`：
   - 复制根目录 `*.ino/*.h/*.cpp/*.c` 到 `build_tmp/`（不含 `stadia/` 等子目录）；
   - **强制**把副本 `config.h` 的 WiFi 两行改写为空（无需手动清空仓库 `config.h`，无 `--with-creds` 选项）；
   - 用 `arduino-cli` 编译（FQBN 必须为 **DIO + USB CDC Enabled + Huge APP**，与 `ARDUINO_SETUP.md` 一致）；
   - `gen_manifest.ps1` 校验副本凭据为空（**非空则报错退出**，防回归），生成 `manifest.json`（含 `credentials:"empty"`、Flash 参数、SHA256）与 `VERSION.txt`，并打包 `固件升级工具_v<版本>.zip`。
3. 把 zip 分发即可。

产物（**发布产物，纳入 git 版本管理**，随发版提交；`build_tmp/` 为中间产物不入库）：
```
firmware/       bootloader.bin / partitions.bin / boot_app0.bin / app.bin
                manifest.json / VERSION.txt
固件升级工具_v<版本>.zip
```

## 五、FAQ

- **浏览器弹不出串口**：需要 Chrome/Edge 89+；确认设备以 USB 数据线连接；其他软件（Arduino IDE 串口监视器等）先关闭占用串口的程序。
- **「连接设备」后握手失败**：重插 USB 再试；换一根数据线（部分线仅供电）。
- **升级中断**：重跑工具重刷即可；仍不行用 `flash_cli.bat`。
- **配网失败/连不上 WiFi**：检查 SSID/密码；错误凭据时先「清除配网信息」再重试；路由器 2.4GHz 频段（设备仅支持 2.4G）。
- **如何确认版本**：网页固件包信息区显示 manifest 版本；设备端 `@ping` 应答 `fw` 字段。
- **如何恢复固件内置凭据**：点「清除配网信息」。

## 六、回退旧固件

保留旧版 `固件升级工具_v<旧版本>.zip`，解压后运行其中的网页工具（或 `flash_cli.bat`）重刷旧 `firmware/` 即可。

## 七、安全

- **分发包强制为空凭据**（构建脚本改写 + 构建期断言），可安全分发，不含任何真实 WiFi 信息。
- 设备 NVS 中以**明文**保存 WiFi 密码（设备本地，仅本设备可读）。
- 网页工具仅监听 `127.0.0.1`，配网数据不经过网络。
